# Support

Ritma is open-source software. Support is best effort, from the maintainers and the community. No response time is promised before v1.0 (see GOVERNANCE.md).

| I want to | Go to |
|---|---|
| Ask a question or get help | GitHub Discussions of this repository |
| Report a bug | A bug report from the issue templates |
| Request a feature | A feature request from the issue templates |
| Report a security vulnerability | SECURITY.md (private advisory only, never a public issue) |
| Report unacceptable behaviour | CODE_OF_CONDUCT.md |

Before opening an issue, check the docs (`docs/`) and the open issues. Include the Ritma version, the install method and the steps to reproduce.

Support covers the latest minor of the current major (BRANCHING.md §5). Older versions receive no fixes; upgrade first.
