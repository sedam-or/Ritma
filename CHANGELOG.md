# Changelog

All notable changes to Ritma are listed here. Entries are generated by release-please from Conventional Commits when a release is cut (RELEASING.md). Released sections are never edited by hand.

Each release lists its changes under the headings Features, Bug fixes, Performance and Reverts. Two extra headings are added when they apply: **Upgrade notes** (steps an operator must take, or "none") and **Policy changes** (policy schema bumps and their migrations, RELEASING.md).
