# Ritma documentation

These pages are for people who run Ritma, not for contributors. Contributor and design docs are the root `CONTRIBUTING.md` and the `spec/` folder.

Each page is tied to the task that writes it. A page that is not yet written is marked **planned**.

| Page | For | Written by | Status |
|---|---|---|---|
| Install (Docker one-liner, compose, Caddy HTTPS) | Owners and IT partners | T-706 | planned |
| One-click deploy templates | Owners with a hosting account | T-707 | planned |
| First run and the 3-step setup | School admins | T-302, T-710 | planned |
| Backup, restore and key rotation | Operators | T-701, T-705 | planned |
| Export everything | School admins | T-702 | planned |
| Observability and alerts | Operators | T-709 | planned |
| Upgrade and release verification | Operators | T-704, T-711 | planned |
| Demo instance | Evaluators | T-708 | planned |

Documentation is written in Bahasa Indonesia first and English second (T-710). Each user-visible change in a release updates its page (RELEASING.md checklist).
